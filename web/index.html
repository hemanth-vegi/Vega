Google Cloud OAuth Setup Guide (Read-Only)

Strictly read-only ('gmail.readonly'). Vega never asks for send, modify, or delete permissions.
1
Create GCP Project & Enable API

In Google Cloud Console, create a project and enable Gmail API (and optionally Google Calendar API).

2
Configure OAuth Consent

Under APIs & Services > OAuth consent screen, choose External, add your Gmail under Test Users, and add scope gmail.readonly.

3
Download credentials.json

Go to Credentials > Create Credentials > OAuth client ID (Type: Desktop app). Download JSON and place it in career_vault/credentials.json.

4
Authenticate & Sync

Label job emails in Gmail as Vega-Career, then click Sync Label Now above to authenticate once and sync alerts & deadlines.
